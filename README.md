# 🚗 Tesla Performance Dashboard (Power BI)

## 📌 Project Overview
This project presents an interactive Power BI dashboard analyzing Tesla’s global business performance and sustainability impact from **2015 to 2025**.

The dashboard focuses on deliveries, production, pricing, regional performance, and CO₂ savings, using a clean star schema data model.

---

## 🎯 Key Objectives
- Analyze global delivery and production trends
- Compare regional performance
- Understand model-wise pricing strategy
- Evaluate sustainability impact through CO₂ savings
- Provide interactive, user-friendly dashboards

---

## 📊 Dashboard Pages
1. **Home Page** – Project overview and navigation  
2. **Dashboard 1 (Executive Overview)** – KPIs and high-level trends  
3. **Dashboard 2 (Deep Dive Analysis)** – Region and model-wise insights  
4. **Dataset Page** – Tabular view of underlying data
